# Курсовий проєкт: Клієнт-Серверна система на Winsock (C++)
### Опис
Цей проєкт демонструє просту клієнт-серверну систему, реалізовану на C++ з використанням Windows Sockets API (Winsock).
Проєкт підтримує виконання трьох різних задач, які обробляються сервером за запитом клієнта:

* Задача 4: Відправка масиву з 5 цілих чисел, сервер знаходить максимальний елемент.

* Задача 5: Відправка числа, сервер порівнює його з власним числом і повідомляє результат.

* Задача 6: Перевірка числа на паліндром.

### Особливості
* Реалізовано багатопоточний сервер, який обробляє кожного клієнта в окремому потоці.

* Кожному клієнту на сервері автоматично присвоюється унікальний ідентифікатор (ID), який відображається в консолі сервера та надсилається клієнту при підключенні.

* Використання RAII класу для коректної ініціалізації та завершення роботи Winsock.

* Чітка структура коду з розділенням загальних функцій, задач клієнта та сервера.

* Простий і зручний текстовий інтерфейс для вибору задачі клієнтом.

### Структура проекту
* Client.cpp — код клієнта, який підключається до сервера та відправляє запити.

* Server.cpp — багатопоточний сервер, що приймає підключення та обробляє запити клієнтів.

* Common.h/cpp — загальні утиліти (Winsock ініціалізація, допоміжні функції).

* Tasks.h/cpp — реалізація трьох основних задач для клієнта і сервера.

### Запуск
1. Запусти server.exe — сервер почне прослуховувати порт 54000.

2. Запусти client.exe — клієнт підключиться до сервера, отримає свій унікальний ID і запропонує вибрати задачу. Можна запустити декілька клієнтів одночастно.

3. Введи номер задачі (4, 5 або 6) та виконати інструкції на екрані.
